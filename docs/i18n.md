# Internationalization

The portable Windows client has built-in `ru-RU` UI strings in `apps/portable-python/gui/i18n.py`.

## Current behavior

The active locale is `ru-RU`; user-facing strings are resolved through the `t(key)` helper in `gui/i18n.py`.

## Adding or changing strings

1. Add or update keys in `apps/portable-python/gui/i18n.py`.
2. Run `python -m unittest discover -s apps/portable-python/tests -q` to verify UI tests still pass.
3. Run `python -m compileall -q apps/portable-python scripts` as the compile gate.

## Review Workflow

AI-generated translations are acceptable as a first draft, but they must keep every key present and non-empty. Before release, review visible flows in the portable client, especially long labels in file lists, transfer status, and pairing dialogs.

Do not add `skip` or `todo` tests for missing translation work. Keep string coverage tests passing instead.
